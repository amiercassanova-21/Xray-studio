## ✨ Fitur Utama

* **⚡ Multi-Protocol Parser & Generator**: Mendukung penguraian dan penggabungan berbagai format akun proxy populer (`vless://`, `vmess://`, `trojan://`) secara instan.
* **⚖️ Dual Routing Strategy**:
  * **LoadBalance (`leastLoad`)**: Menyebar beban trafik secara cerdas ke node dengan latensi dan kapasitas terbaik (ideal untuk streaming, download, dan browsing harian).
  * **Best Ping (`leastPing`)**: Otomatis memilih node tercepat berdasarkan pengujian berkala (ideal untuk gaming online dan responsivitas tinggi).
* **📁 Drag-and-Drop & Profile Manager**: Memungkinkan pengguna menyeret file langganan (`.txt` / `.json`) langsung ke area input serta menyimpan beberapa profil konfigurasi di `localStorage`.
* **🎨 Luxury 3D Gold UI & Responsive Design**: Antarmuka modern bernuansa gelap dengan aksen emas mewah, tombol interaktif 3D, dan desain yang sangat responsif di perangkat seluler maupun desktop.
* **🔒 100% Client-Side Security**: Seluruh proses parsing dan konversi berjalan secara lokal di dalam browser Anda. Tidak ada data akun proxy yang dikirimkan ke server eksternal.

---

## 🚀 Cara Penggunaan

1. Buka halaman utama aplikasi atau jalankan secara lokal.
2. Pilih mode strategi routing di panel kiri (**LoadBalance** atau **BestPing**).
3. Tempel link akun proxy Anda (atau gunakan tombol **Sample** untuk mencoba data pengujian).
4. Konfigurasi parameter lanjutan opsional (seperti port SOCKS/HTTP, Probe URL, dan Interval).
5. Klik **Generate Xray JSON**.
6. Salin hasil konfigurasi atau unduh sebagai file `.json` untuk diimpor ke klien Xray Anda (seperti v2rayNG, v2rayN, Clash, dll.).
